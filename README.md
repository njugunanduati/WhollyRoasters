# Wholly Roasters

Wholly Roasters is Marc’s artisanal coffee roastery for coffee shops and cafés. Marc sources, roasts, and packages coffee beans so café teams can focus on brewing and serving quality coffee to their customers.

This repository contains a small Flask app with a welcome page at `/` and an About page at `/about`.

## Run locally

From the repository root, install Flask and start the development server:

```sh
python -m pip install Flask
python -m flask --app app run
```

Open `http://127.0.0.1:5000/` for the welcome page or `http://127.0.0.1:5000/about` for the About page.
